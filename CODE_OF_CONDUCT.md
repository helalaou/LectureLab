# Code of Conduct

LectureLab follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give constructive feedback, and focus on
what is best for the people who use and build this project. Harassment, discrimination and
personal attacks are not tolerated in any project space.

Report unacceptable behaviour to the maintainer through a private
[GitHub security advisory](https://github.com/helalaou/lecturelab/security/advisories/new) or by
contacting the repository owner directly. Reports are handled confidentially.
